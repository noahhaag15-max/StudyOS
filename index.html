☁️ Cloud Sync (GitHub Gist)
Synchronisiere deine Daten zwischen Laptop und PC über einen privaten GitHub Gist.
Einmaliges Setup: 1. Auf github.com/settings/tokens → "Tokens (classic)" → "Generate new token (classic)"
2. Name z.B. "StudyOS Sync", Expiration "No expiration", nur den Scope gist ankreuzen
3. Token kopieren (beginnt mit ghp_) und unten einfügen
4. Auf beiden Geräten denselben Token verwenden
